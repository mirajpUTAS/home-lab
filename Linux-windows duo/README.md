# 🖥️ Windows & Ubuntu Dual-Boot Lab
### Operating Systems • Systems Administration • Performance Analysis

## 📌 Project Overview

Windows and Linux are two widely used operating-system platforms, each with its own architecture, strengths and use cases. Windows is common in homes and workplaces because of its broad software compatibility, familiar desktop experience and integration with business applications. Linux, on the other hand, is open source, highly configurable and available in many distributions designed for everyday computing, software development, system administration and cybersecurity.

Rather than comparing these platforms only in theory, this project explores how they operate in practice when installed on the same physical computer.

I will configure a dual-boot environment with **Windows and Ubuntu**, allowing me to select an operating system when the computer starts. I will document the installation process, examine the disk partition layout, investigate the boot process and verify that both operating systems work correctly on the same hardware.

Beyond installation, I want to investigate how each environment performs across selected tasks. Where practical, I will compare boot times, storage usage, memory consumption and performance in comparable workloads, while documenting the testing conditions and limitations.

The goal is not to declare one operating system the winner. It is to understand their differences, identify their strengths and trade-offs, and develop practical skills in operating-system installation, storage management, boot configuration, troubleshooting and performance analysis.

## 🎯 Project Objectives

- Install and configure Windows and Ubuntu on one physical computer.
- Understand disk partitioning, filesystems and storage allocation.
- Explore UEFI firmware, boot entries and the bootloader used by the system.
- Verify that both operating systems start successfully and recognise the hardware.
- Measure selected performance indicators under documented testing conditions.
- Compare the usability, resource requirements, software compatibility and administration experience of both environments.
- Record the process through screenshots, terminal output, diagrams and troubleshooting notes.

## 🔬 Key Questions

1. How does the dual-boot process allow two operating systems to coexist on one computer?
2. How are storage partitions and boot options configured?
3. What differences can be observed in resource usage and performance under comparable workloads?
4. Which tasks are more convenient in each environment, and why?
5. What configuration challenges, compatibility issues or recovery considerations should be understood before setting up a dual-boot machine?

## 📊 Expected Outcome

The outcome will be a documented, reproducible home-lab project that demonstrates the configuration and verification of a dual-boot environment. Findings will be based on actual tests and observations rather than assumptions about which operating system is better.

The project will also serve as a practical reference for anyone interested in learning about Windows, Ubuntu and operating-system administration.
